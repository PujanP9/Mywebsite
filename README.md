# Pujan Poudel — Personal Portfolio

Premium static portfolio for Pujan Poudel, focused on IT support, digital technology and practical software projects.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server.

## Deploy

This project is static HTML/CSS/JavaScript and can be deployed directly to GitHub Pages, Netlify or Vercel.

## Included

- Responsive personal portfolio
- Animated hero and scroll reveals
- Custom desktop cursor
- Interactive magnetic buttons
- Featured Imposter Nepal case study
- Resume download
- Responsive project gallery
- Accessibility/reduced-motion support
- SEO metadata
